# pSEO-шаблоны страниц Катран-Пневмо

Источник данных: `seo_wordlist.md` (словник с частотностями), `seo_glossary_wiki.md` (термины).
Валидация запросов: Yandex MCP `marketing_keyword_research` (Wordstat), релевантность — сверка с каталогом (`data.json`).
Правила: уникальный контент каждого блока, единицы параметров по глоссарию, не повторять текстовые блоки между страницами одного кластера (размножение = санкции). Все заготовки — редакторские слоты с полями.

## Типы страниц

| Тип | URL-скелет | Формула H1 | Источник словника |
|---|---|---|---|
| Категория | `/catalog/[cat-slug]/` | `Купить [тип] пневматический — цена, каталог` | категория |
| Товар | `/product/[model-slug]/` | `[Модель] ([бренд, тип])` | модель |
| Сценарий | `/solutions/[тип]-для-[сценария]/` | `[Тип] для [сценарий] — выбор и применение` | задача/сценарий |
| Параметрика | `/catalog/[тип]-[параметр]/` | `[Тип] [параметр] — купить` | параметрика |
| Wiki-термин | `/glossary/[термин]/` | `[Термин] — что это, как работает` | глоссарий |
| Как выбрать | `/guide/kak-vybrat-[тип]/` | `Как выбрать [тип] — 6 критериев` | информация |

## Шаблон A. Страница категории (тип)

### Мета
- **Title (≤70):** `Купить [тип] пневматический в СПб — цена, наличие | Катран-Пневмо`
- **Description (≤155):** `Купить [тип] пневматический в Санкт-Петербурге от Катран-Пневмо. [Ключевой параметр или число моделей]. Доставка по России, гарантия [12+ мес]. Цена от [цены от].`
- **H1:** `Купить [тип] пневматический`

### Контент-блоки
1. **Интро (2–3 абзаца):** что за тип, для чего, чем выгоден пневматический привод в сравнении с электрическим (не перегревается, работает во взрывопожароопасных зонах, не зависит от сети). Ключ в первом абзаце.
2. **Для каких задач** — список применений (5–7 пунктов).
3. **Как выбрать / на что смотреть** — энергия удара (Дж), расход воздуха (л/мин), хвостовик, рабочее давление 0,63 МПа, бренд, ресурс.
4. **Каталог позиций** — автоматическая сетка товаров (id компонент, не дублировать текстом).
5. **Использование с компрессором** — какая производительность требуется (связь на инфо-страницу компрессора).
6. **FAQ (5 вопросов, схема JSON-LD FAQPage):** какой компрессор нужен; чем отличается от [электро-аналога]; какие насадки/оснастка; расход воздуха; берем ли в лизинг/на КАП. Куда доставите.
7. **Смежные категории** (перелинковка): [тип 2], [тип 3], оснастка, запчасти.

## Шаблон B. Страница товара (модель)

- **Title (≤70):** `[Модель] — купить, цена | Катран-Пневмо`
- **Description (≤155):** `Купить [модель] [тип] в СПб. [Ключевые характеристики: энергия Дж, расход л/мин, вес]. Доставка по России, гарантия [12+] месяцев.`
- **H1:** `[Модель] [тип]`
- **Блоки:** интро → предназначение/задачи → таблица характеристик → комплектация → преимущества пневмопривода → аналоги (смежные модели с ценами) → FAQ (компрессор, оснастка, покупка) → словник ключей под текстом.
- Шаблон реализован в `seo_hammers.md`, `seo_TP-28A.md`, `seo_TPV-3A.md` — использовать их как эталон заполнения.

## Шаблон C. Сценарий `[тип] для [сценарий]`

Сценарии (из словника): автосервис, шиномонтаж, грузовые автомобили, строительство/демонтаж, литейное производство, покраска, монтаж.
- **Title:** `[Тип] для [сценарий]: какой выбрать | Катран-Пневмо`
- **H1:** `[Тип] для [сценарий]`
- **Блоки:** специфика задач на объекте → рекомендуемые параметры (момент/энергия/размер головок) → какие модели каталога подходят (карточки) → оснастка и обвязка (шланг/масло/головки) → компрессор под сценарий → FAQ.
- Уникализация: каждый сценарий строит свою «картину применения» и свой набор моделей — не клонировать категорийные тексты.

## Шаблон D. Параметрика `[тип] [параметр]`

Примеры: `пневмогайковерт 1/2"`, `отбойный молоток моп`, `пневмозубило для автосервиса`, `гайковерт для грузовых`, `пневмошланг 8 мм`.
- **Title:** `[Тип] [параметр] — купить | Катран-Пневмо`
- **H1:** `[Тип] [параметр]`
- **Блоки:** что означает параметр (единицы по глоссарию) → кому подходит → модели каталога с этим параметром → головки/оснастка → FAQ (1–3 вопроса).
- Приоритет создания: частотность ≥ 50 и наличие ≥ 3 позиций в каталоге под параметр.

## Шаблон E. Wiki-термин `[термин] — что это`

- **URL:** `/glossary/[slug]/`
- **Title:** `[Термин] — что это, назначение и применение | Катран-Пневмо`
- **H1:** `[Термин] — что это`
- **Блоки:** определение (2–4 предложения из глоссария) → как работает / из чего состоит → для чего используется → чем отличается от [частая путаница] → какие модели продаём (карточки) → смежные термины (перелинковка глоссария) → FAQ.
- Расшифровка моделей (МОП, МО, КМП, ИП-4126, ПШМ) — отдельные термины с целевым переходом на карточки.
- Объем: 800–1500 слов, уникальные тексты, LSI из глоссария.

## Шаблон F. Как выбрать `kak-vybrat-[тип]`

- **Title:** `Как выбрать [тип]: критерии, параметры, компрессор`
- **H1:** `Как выбрать [тип]`
- **Блоки:** задачи → параметры (таблица критериев) → подбор компрессора (л/мин, давление) → оснастка → ошибки новичков → рекомендации по каталогу → FAQ.
- Связать со словником «информационных» запросов (какой компрессор нужен, как выбрать).

## Общие правила генерации

1. **Семплирование:** каждую страницу генерить только при наличии релевантного словника (≥ 5 ключей) и товаров (≥ 3).
2. **Релевантность перед публикацией:** прогон `marketing_keyword_research` по H1; если запрос уводит в стоп-термины (электрический, аккумуляторный, авто-блоки и т.д.) — раздел исключить.
3. **Уникальность:** модули-блоки не копипастить; повторно использовать только шаблонную обвязку (перелинковка, FAQ-структура), текст блоков уникальный.
4. **Мета-длины:** Title ≤ 70, Description ≤ 155, первый абзац с ключом.
5. **Схемы:** FAQPage, Product (json-ld) на товарных и сценарийных страницах; BreadcrumbList на всех.
6. **SEO-текст товара:** отдельный чек-лист эталон — карточки из `seo_hammers.md` / `seo_TP*.md`.
7. **Приоритет очереди:** 1) категории без SEO-текста, 2) товары-бестселлеры и патентные, 3) сценарии с частотностью ≥ 200, 4) wiki-термины, 5) «как выбрать» по топ-кластерам.
